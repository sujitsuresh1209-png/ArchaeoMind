# ArchaeoMind: Lost Civilization - AI Design

## STRICT REQUIREMENTS
The in-game AI is strictly symbolic and deterministic. 

**Prohibited Technologies:**
- Machine learning (ML)
- ML datasets or training
- TensorFlow, PyTorch, scikit-learn, etc.
- Runtime LLM APIs (OpenAI, Gemini, etc.)

## Symbolic AI Engine Features
- **Knowledge Representation & Base**: Stores facts and rules about the game world.
- **Rule Engine**: Processes logical rules.
- **Forward & Backward Chaining**: Infers new facts from existing data or determines required conditions for goals.
- **Constraint Solving**: Resolves conflicting goals or requirements.
- **Knowledge Graph**: Maintains relationships between entities.
- **Temporal Reasoning**: Tracks events and causality over time.
- **Hypothesis Generation & Evaluation**: Forms and tests theories based on discoveries.
- **Explainable AI**: The reasoning process can be fully traced and explained to the player.
