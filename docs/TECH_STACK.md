# ArchaeoMind: Lost Civilization - Technology Stack

## Core Technologies
- **Frontend**: React, TypeScript, Vite
- **Styling**: Tailwind CSS
- **State Management**: Zustand
- **3D Graphics**: Three.js, React Three Fiber, Drei
- **Backend & Database**: Supabase, PostgreSQL
- **AI**: Custom TypeScript Symbolic AI

## Responsibilities
- **React**: Presentation layer, UI components, layout structure.
- **Three.js & R3F**: 3D rendering, handling the 3D scene, models, and spatial representation of the game world.
- **Zustand**: Global state management, separating game state from React component state.
- **Supabase**: Persistent storage, user authentication (future), real-time syncing if required in later phases.
- **Custom TS AI**: Deterministic reasoning engine, knowledge representation, constraint solving, forward/backward chaining.
